Handicap Formula

Handicaps apply to second-half (HC) fixtures and are based on each shooter's average over their last 3 matches. The formula is max(0, round(((target − avg) ÷ divisor − offset) × factor)).

Data Backup & Restore

Download every season, team, shooter, fixture and score as one file and keep it somewhere safe. To recover after data loss: create a fresh Supabase project, run supabase/schema.sql then everything in supabase/migrations/ to rebuild the empty database, point the site at the new project, then restore from a backup file here. This only covers table data — login accounts aren't included (re-invite admins/captains and reassign their role/team afterwards). For a complete Postgres-level backup (schema, functions, RLS policies and all), see supabase/BACKUP_RESTORE.md in the repo.
